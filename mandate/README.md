# Agent Mandate

A mandate is a signed delegation of authority that is bounded and can be revoked. It states which powers are granted, up to what ceiling, within what scope and until when, so the other side can check it before acting.

Agent Mandate is a Common Agent Standard, kept in the [Common Agent Standards repository](https://github.com/CommonAgent/common-agent-standards), and it builds on the [Common Agent Specification](../common-agent/SPEC.md).

## What is here

- [SPEC.md](SPEC.md): the specification, version 0.8.0-draft, status Working Draft.
- [CHANGELOG.md](CHANGELOG.md): the versions tagged in this repository.

## Versions

Each version is tagged as `mandate-v` followed by the version, such as
`mandate-v0.4.0-draft`, and has a release on GitHub. The site of the standard is
<https://agentmandate.net/>.
