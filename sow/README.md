# Agent SoW

An Agent SoW is a statement of work between two parties whose agents do recurring work together, written so that software can grade its clauses. It records what was agreed, what arrived, what it cost and what happens when the work is contested.

Agent SoW is a Common Agent Standard, kept in the [Common Agent Standards repository](https://github.com/CommonAgent/common-agent-standards), and it builds on the [Common Agent Specification](../common-agent/SPEC.md).

## What is here

- [SPEC.md](SPEC.md): the specification, version 0.26.0-draft, status Working Draft.
- [SPEC-A2A-TERMS.md](SPEC-A2A-TERMS.md): A2A Terms extension, version 0.1.1-draft.
- [SPEC-A2A-INTERVIEW.md](SPEC-A2A-INTERVIEW.md): A2A Interview extension, version 0.1.1-draft.
- [conformance/](conformance/): the test fixtures for the clauses on pricing, data use, the Agent NDA reference, disputes, reporting, subcontracting, liability and service floors, which software that grades an Agent SoW checks itself against.
- [CHANGELOG.md](CHANGELOG.md): the versions tagged in this repository.

## Versions

Each version is tagged as `sow-v` followed by the version, such as
`sow-v0.23.0-draft`, and has a release on GitHub. The site of the standard is
<https://agentsow.com/>.
