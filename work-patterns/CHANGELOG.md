# Changelog

Versions of Agent Work Patterns tagged in this repository, newest first. A version is
tagged as `work-patterns-v` followed by the version, and the text in this folder at
that tag is the text of that version. Its history comes from jeffrschneider/agentworkpatterns.

## v1 (2026-08-19)

The first version tagged in the Common Agent Standards repository, as
`work-patterns-v1`. Every pattern and the planning guide carry Version: v1.
