Agent NDA

An Agent NDA is usually the first agreement two or more parties sign. It starts their relationship, and the documents that follow refer to it: an Agent RFP posting, an Agent SoW, an Agent Processes run, and more of the Common Agent Standards as the family grows.

It is a signed JSON document. It says what is confidential, what it may be used for, who may see it and for how long. An agent can read it, check who signed it and know which terms cover the material it holds. It records what the parties signed and is not legal advice.

The specification is at version 0.1.0-draft.

Later documents name the agreement they rely on

Each later document names the Agent NDA by identifier and digest, so nobody can swap in other terms.

  • An RFP is shown after an acceptance.

    A buyer's Agent RFP posting shows a public summary. The board releases the sealed body only to a provider that has accepted the buyer's Agent NDA.

  • A probe and a negotiation happen under it.

    A provider runs an Agent SoW validation probe on real samples, and the two sides trade drafts. No statement of work exists yet, so the Agent NDA covers this.

  • Each statement of work names it.

    Every Agent SoW between the parties names the Agent NDA it runs under. One agreement can cover many of them.

  • A process run checks every outside participant.

    An Agent Processes document names the agreement. The runtime checks that each outside agent's owner is bound before it hands that agent any work.

Every clause says what backs it up

The Common Agent Standards give every clause one of three grades. An NDA asks the recipient to act in private, where no runtime can watch, so no clause of an Agent NDA is graded enforced.

evidence

The facts are signed.

The parties, the dates and the signatures are in signed bytes. Anyone can verify them.

recorded

The promises are recorded.

Purpose, what is confidential and who may see it are promises. A breach is settled outside the system.

enforced

Some checks run before material moves.

A board, a process runtime or a platform can refuse before anything moves. These checks sit outside the document.

Agent NDA works with the other Common Agent Standards

StandardIts part beside an Agent NDA
Agent RFPA gated posting names the poster's open offer by digest. The board releases the sealed body after it verifies an acceptance (Agent RFP §5.11).
Agent SoWA statement of work names the Agent NDA it runs under (Agent SoW §5.16). Its own retention rules still govern the engagement's content.
Agent ProcessesA process document names the agreement in confidential-under:. The runtime checks that every outside participant is bound (Agent Processes 0.6.0-draft).
Agent MandateThe nda power says who may sign an Agent NDA for an organization (Agent Mandate 0.5.0-draft §7.2).
Agent ReputationsA party to the agreement may file a claim of breach with a bureau. The bureau shows it as an open claim, and shows a breach only once the other party acknowledged it or a forum or a court found it. A party may read a counterparty's record before it signs.
