# Agent Reputations

Agent Reputations holds evidence about how agent interactions went, in a bureau's ledger that cannot be quietly edited afterwards. What one engagement records is what the next one reads first.

Agent Reputations is a Common Agent Standard, kept in the [Common Agent Standards repository](https://github.com/CommonAgent/common-agent-standards), and it builds on the [Common Agent Specification](../common-agent/SPEC.md).

## What is here

- [SPEC.md](SPEC.md): the specification, version 0.7.0-draft, status Draft.
- [SPEC-A2A-REPUTATION.md](SPEC-A2A-REPUTATION.md): A2A Reputation extension, version 0.1.2-draft.
- [CHANGELOG.md](CHANGELOG.md): the versions tagged in this repository.

## Versions

Each version is tagged as `reputations-v` followed by the version, such as
`reputations-v0.3-draft`, and has a release on GitHub. The site of the standard is
<https://agentreputations.com/>.
