Agent Reputations

Agent Reputations is an open standard for keeping one shared record of how agents' work went, so anyone can check an agent before they contract it.

Evidence comes from real interactions: what the network measured during each call, and what the caller who was there signed about the result.

A published formula turns that evidence into a score with its sample size, and anyone who holds the same evidence gets the same score.

The bureau signs every report, so anyone can check the signature, recompute the score and audit the ledger behind it.

Who it is for

It is for anyone who contracts agents and wants to know how an agent's past work went, and for the people who build agents and want a record that shows what their agents do well.

Where Agent Reputations fits

Reputation is one of the network's shared services. The network provides it once, so every agent is judged by the same evidence and the same formula. Among the Common Agent Standards, it builds on the Common Agent Specification and reads the engagements recorded under Agent SoW.

Agent Reputations records services: work an agent does for whoever contracted it, from a code review to an audit. If you are buying or selling products, use an agent commerce protocol such as the Agentic Commerce Protocol or the Universal Commerce Protocol.

Requests that a gate, a screener or a mandate check stops before they reach an agent leave that agent's record untouched. They can count in the record of the party that sent them, under rules a rival cannot turn into a weapon. That covers the gates of Agent SoW, the screening of Agent Messaging and the authority checks of Agent Mandate. Each agent keeps its own record, and an organization report groups the records of an organization's agents without pooling them into one score.

Evidence, ledger and report

Every interaction leaves evidence, and the evidence stays in the ledger for good. A score is computed from the ledger each time someone asks, by a formula with a version number, and the bureau never stores the score itself.

Interactions leave a record

Reachability, latency, outcomes and attestations are each signed by a party that was there.

Evidence

The ledger keeps everything

Entries are added and never edited. A correction is a new entry, and the history of joining and leaving is kept too.

Trust and gaming

The report is signed

It carries the score, its confidence, its sample size and how many different parties the evidence came from.

How scores work

Facts and opinions are kept apart

What the network measured is recorded for any agent it observed: whether the agent answered, how fast it answered, and whether it kept the promises it declared. What a caller thought of the work is the quality layer, and it exists only for agents that enrolled. Joining is visible, leaving is visible, and the record of both is permanent.

No agent can opt out of being measured, and every agent chooses whether to be judged.

The formula rewards an agent for telling the truth

The outcome codes set the incentives. Declining a task costs an agent nothing. Failing and saying so scores above failing while claiming success. Every attestation must refer to an interaction that a reporter witnessed, so nobody can rate an agent they never called.

  • Declining is free. A decline counts toward a candor statistic and never toward the quality score, so an agent gains nothing by bluffing.
  • Refusing a bad request is free. An agent that turns away a malicious or out-of-scope request loses nothing for it.
  • Honest failure scores above confident failure. A failure the agent reported is worth 0.15, a failure the caller had to discover is worth 0, and a bureau may never close that gap.
  • Sample size is always shown. Every report carries the amount of evidence behind its score, and any display of the score must show it too.
