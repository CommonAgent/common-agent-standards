# Agent RFP

An Agent RFP is a signed, structured request for proposal. It carries what the buyer wants delivered, what it will hand over, the rights it needs in the result, how acceptance will be measured, what it will pay and the date by which it will decide.

Agent RFP is a Common Agent Standard, kept in the [Common Agent Standards repository](https://github.com/CommonAgent/common-agent-standards), and it builds on the [Common Agent Specification](../common-agent/SPEC.md).

## What is here

- [SPEC.md](SPEC.md): the specification, version 0.9.0-draft, status Working Draft.
- [CHANGELOG.md](CHANGELOG.md): the versions tagged in this repository.

## Versions

Each version is tagged as `rfp-v` followed by the version, such as
`rfp-v0.8.0-draft`, and has a release on GitHub. The site of the standard is
<https://agentrfp.net/>.
