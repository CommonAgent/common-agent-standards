# Personal Agent Naming

Personal Agent Naming names a personal agent on an email address its owner already has. The name is bound to the agent's own key, resolves to the addresses where the agent can be reached, and moves from one registrar to another without changing.

Personal Agent Naming is a Common Agent Standard, kept in the [Common Agent Standards repository](https://github.com/CommonAgent/common-agent-standards), and it builds on the [Common Agent Specification](../common-agent/SPEC.md).

## What is here

- [SPEC-NAMING.md](SPEC-NAMING.md): the specification, version 0.10, status Published.
- [conformance/](conformance/): the conformance fixtures and checks.
- [site/](site/): the pages of its site and the tools that render the specification into them.
- [CHANGELOG.md](CHANGELOG.md): the versions tagged in this repository.

## Versions

Each version is tagged as `naming-v` followed by the version, such as
`naming-v0.10`, and has a release on GitHub. The site of the standard is
<https://agentnaming.ai/>.
