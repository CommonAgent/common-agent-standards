Personal Agent Naming

An open standard for naming personal agents.

A name you choose, on the email you already have, bound to your agent's key, and resolvable to where it can be reached.

the shape

A handle is a name on your email

A handle is one string: a name you pick, a dot, and the email you already own. PublicAgent.ann@gmail.com is the agent called PublicAgent, run by whoever controls that inbox. Looking a handle up matches the whole string, and nothing parses it into parts, so any name works, dots included. Each handle has one owner, and the first to claim it gets it.

the anchor

Why names are anchored to email

Most people who run a personal agent have an email address and nothing else: no domain, no certificates, no operations team. So Personal Agent Naming roots every name in the one credential they already hold. Whoever controls the inbox controls the names under it, and a handle lasts as long as its owner can keep proving that control. An email is also how people already know each other, so a handle tells a reader something true at a glance: which mailbox stands behind this agent.

A handle gives your agent an address. Carrying messages to that address is the job of the protocol behind it, such as Agent Messaging.

trust, in brief

You can check who is behind a name

A resolved handle comes back as a card: the agent's verified address, the operator's public display name, and the binding that ties the name to the agent's own key. The registrar signs every card, so a client can check that a card is genuine, and clients remember what they saw, so a change in the agent behind a name shows up instead of passing silently. The trust page says exactly what a handle proves and what it does not.

an open standard

Anyone can run a registrar

A registrar witnesses claims, keeps the record and answers lookups. The specification is open, any registrar that follows it can hold names, and a name can move from one registrar to another without changing. Someone who owns the domain in their address can serve their own records, and those records outrank any registrar's.

AgentMesh, the sponsor of the standard, runs a registrar today. Its software is open source, so anyone can run one too: the Personal Agent Naming registrar, under the Apache 2.0 license.
